# Бот - инструкция (запуск на своем ПК)

## 1. Установка
```powershell
cd telegram-bot
pip install -r requirements.txt
```

## 2. Запуск
```powershell
python bot.py
```
Бот работает пока открыто окно. Хост - твой ПК, как ты и хотел.

## 3. Узнать свой ID для админки
1. Запусти бота, отправь ему `/myid`
2. Скопируй число
3. Открой файл `telegram-bot/.env`, впиши:
```
ADMIN_IDS=твое_число
```
4. Перезапусти бота (`Ctrl+C`, потом `python bot.py`)
5. Команда `/admin` - панель: добавить / удалить / статистика / рассылка

## 4. Как поменять названия разделов (Казань, Севастополь, Пермь, ЦП)
Файл: `telegram-bot/config.py`, строки:
```python
CATEGORIES = {
    "kazan": "Казань",
    "sevastopol": "Севастополь",
    "perm": "Пермь",
    "cp": "ЦП",
}
```
- Меняй ТОЛЬКО текст справа (`"Казань"` и т.д.)
- Ключи слева (`kazan`, `cp`...) не трогай
- Сохрани файл и перезапусти бота

Приветствие меняется там же: `GREETING_TEXT`.

## 5. Как поменять лого (фото приветствия)
Сейчас стоит заглушка - белый квадрат: `telegram-bot/assets/logo.png`
Просто замени этот файл своим лого (оставь имя `logo.png`).
Бот при `/start` отправляет это фото + приветствие.

## 6. Как добавить позиции (что скидывает бот)
Вариант А - через админку (проще):
`/admin` -> `➕ Добавить позицию` -> выбрать раздел -> название -> описание -> фото/файл

Вариант Б - база `bot.db`, таблица `items` (создается сама при первом запуске).

Пользователь жмет раздел -> видит список -> жмет кнопку или пишет название текстом -> бот скидывает фото/файл.

## 7. Безопасность
Токен в `.env` - не кидай его в интернет и не коммить в git.
Если токен засветился - пересоздай у @BotFather: `/mybots` -> твой бот -> `API Token` -> `Revoke`.
